= Quickstart
:description: Minimal sconstruct and sconscript to build and test with cuppa

== Minimal sconstruct

Place this next to your project root (or higher in the tree if you use `-D`):

[source,python]
----
import cuppa

cuppa.run()
----

== Minimal sconscript

In a directory of `.cpp` files:

[source,python]
----
Import('env')

for source in env.GlobFiles('*.cpp'):
    env.Build(str(source)[:-4], source)
----

`env.Build()` is toolchain- and variant-aware (unlike vanilla SCons `Program()`).
`GlobFiles` lists one directory when the sconscript runs. For nested
trees use `env.RecursiveGlob`. SCons `env.Glob` is also single-directory
only — it does not recurse with `**`.

== Building

From the project (or a subdirectory):

[source,sh]
----
cuppa -D
----

The `-D` SCons flag walks up to find the `sconstruct`, then runs `sconscript` files relative to your starting directory.

Default variants are typically debug and release for the platform default toolchain. Restrict them:

[source,sh]
----
cuppa -D --dbg
cuppa -D --rel
----

== Tests

Treat sources as test binaries:

[source,python]
----
Import('env')

for source in env.GlobFiles('*.cpp'):
    env.BuildTest(str(source)[:-4], source)
----

Build and run tests:

[source,sh]
----
cuppa -D --dbg --test
----

Use `--show-test-output` to print stdout/stderr from test processes.

== Auto-enable a built-in dependency

Built-ins such as source Boost are **already registered** with Cuppa. You do not list them in
`import_dependencies`. Pass them to `auto_enable_dependencies` so every `sconscript` gets
`BuildWith('boost')` automatically. Unpinned Boost resolves to the latest release on the download
path (see xref:dependencies/builtins/boost.adoc[Boost]); optionally pin a local tree with
`boost-location` / `boost-home` in `default_options`.

[source,python]
----
import cuppa

cuppa.run(
    auto_enable_dependencies = [
        'boost',  # unpinned → latest on the download path
    ],
)
----

Custom factories from `package_dependency` / `location_dependency` still need
`import_dependencies` (and usually the same object in `auto_enable_dependencies`). See
xref:concepts.adoc#sconstruct-api[cuppa.run() parameters].

In a `sconscript`, select libraries with `use_libs` on the `BuildWith` return value (preferred
over `BoostStaticLibs`):

[source,python]
----
Import('env')

env.BuildWith('boost').use_libs([
    'system',
    'filesystem',
])

env.BuildTest('my_test', 'my_test.cpp')
----
