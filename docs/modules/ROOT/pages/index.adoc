= Cuppa
:description: Extensible C++ build system built on SCons

Cuppa is an extensible build system for C++ projects that sits on top of https://www.scons.org/[SCons].
It keeps `sconscript` files declarative while handling toolchains, build variants, dependencies, tests, and coverage.

== Why cuppa?

* *Make-like CLI* -- from anywhere under your project tree, run `cuppa -D` (or `scons -D`) and cuppa builds the relevant `sconscript` files.
* *Multi-toolchain, multi-variant* -- build debug, release, and coverage variants against GCC, Clang, and MSVC in one invocation.
* *Dependencies as vocabulary* -- Boost, Qt, location-based header libraries, and GitLab package registry packages are first-class.
* *Tests and coverage* -- `BuildTest`, runners, gcovr HTML/JSON reports, and coverage index collation.

== Design principles

Cuppa aims to:

* keep `sconscript` files declarative and free of build-system logic
* give experts a place to encapsulate dependency and toolchain knowledge once
* codify SCons best practices so callers express *intent* (`Build`, `BuildTest`, `BuildWith`) rather than low-level flag plumbing
