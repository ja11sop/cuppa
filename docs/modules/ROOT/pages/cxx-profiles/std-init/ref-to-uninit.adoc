= std::init: pointer and reference marking (`ref_to_uninit`)
:description: std::init rule ref_to_uninit — ref_to_uninit binding consistency

include::partial$cxx-profiles/attribute-markers.adoc[]

== What this rule checks

Bindings between pointers or references and storage must match `{cxx-a-ref-to-uninit}`
marking:

* Unmarked pointers or references to **uninitialized** storage are rejected.
* Marked `{cxx-a-ref-to-uninit}` bindings to **initialized** storage are rejected.
* Passing a marked pointer to an unmarked parameter is rejected (no credit transfer).

== Example violations

From `examples/profiles/std-init-violations/ref_to_uninit.cpp`:

[source,cpp]
----
void bind_unmarked_pointer_to_uninit()
{
    int Storage [[uninit]];
    int* Pointer = &Storage; // needs [[ref_to_uninit]]
}

void bind_marked_pointer_to_initialized()
{
    int Initialized = 7;
    int* Pointer [[ref_to_uninit]] = &Initialized; // must not be marked
}
----

== Expected Clang diagnostics

[source]
----
error: pointer to uninitialized memory must be marked '[[ref_to_uninit]]' under profile 'std::init'
error: pointer marked '[[ref_to_uninit]]' must refer to uninitialized memory under profile 'std::init'
----

== Resolutions

* Add `{cxx-a-ref-to-uninit}` when binding to storage that is (and remains) intentionally
  uninitialized at the point of binding.
* Remove the marker when binding to initialized storage.
* Mark callee parameters `{cxx-a-ref-to-uninit}` when they accept uninitialized buffers, or mark
  the callee `{cxx-a-now-init}` when it initializes the pointee.
* **Suppress** at API boundaries the analyzer cannot model.
