= std::init profile
:description: Initialization profile rules (std::init) with Clang examples and diagnostics

include::partial$cxx-profile-attribute-markers.adoc[]

The **std::init** profile is the initialization slice of ISO {cpp} Profiles described in link:https://wg21.link/P4222[P4222] — _An initialization profile_. Alliance Clang implements an experimental subset; cuppa passes `--cxx-profiles-enforce=std::init` through to every {cpp} translation unit (see xref:cxx-profiles.adoc#how-cuppa-enables[How cuppa enables Profiles]).

This section documents each **rule family** enforced under `std::init`: what problem it
catches, a minimal violation example, the diagnostic Clang emits today, and typical fixes.
Other compilers are not covered yet.

== Example project

All examples on these pages come from the deliberate-violation fixture:

`examples/profiles/std-init-violations/`

Build it with a Profiles-capable Clang (the compile **should fail**):

[source,bash]
----
cd examples/profiles/std-init-violations
cuppa -D --dbg --offline \
  --toolchains=clang24_profiles_2026_08_07_27 \
  --cxx-profiles --cxx-profiles-enforce=std::init \
  --cxx-disable-error-limit -i
----

See the fixture README for `sconstruct` / `sconscript` layout and notes on running cuppa
from an installed package versus a checkout.

== Suppressing a rule

When a violation is intentional (for example a buffer filled by an external API), apply
`{cxx-a-profiles-suppress}` on the declaration
or statement. See
link:https://github.com/cppalliance/clang/blob/profiles-framework/clang/docs/ProfilesFramework.rst[ProfilesFramework.rst]
for the full suppression grammar.
