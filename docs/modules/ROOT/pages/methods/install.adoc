and packaging examples under xref:methods/packages.adoc[Packages].

== Behaviour (draft)

[cols="1,3"]
|===
| Returns | Install nodes
| Evaluation | Build action
| Output paths | Caller-chosen destination; Cuppa projects often stage under variant `final/` or a package directory
| Progress | When install nodes are attached to NotifyProgress via a Cuppa method that owns the targets
|===
