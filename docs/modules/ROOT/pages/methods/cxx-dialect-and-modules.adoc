= C++ dialect, modules, and Profiles methods
:description: StdCpp, modules helpers, and Profiles / error-limit controls

This page covers dialect selection, {cpp}20 modules helpers, and Profiles / diagnostic-cap
controls on the environment. Flag mutation helpers such as `ReplaceFlags()` and `MergeFlags()` live
on xref:methods/flags-and-toolchain.adoc[Flags and toolchain].

== Behaviour summary

[cols="1,3",options="header"]
|===
| Axis | Detail

| Returns | Env mutators return env (or `None`); `Module()` / `HeaderUnit()` return nodes
| Evaluation | Immediate (flags / Profiles) or build action (modules compile)
| Output paths | TU objects mirror sources under `working/`; BMIs under `modules/`
| Progress | Compile-path emitters yes; flag / Profiles mutators no
|===

== Methods

[cols="2,3"]
|===
| Method | Role

| `env.StdCpp(standard)`
| Set the {cpp} dialect for this env (for example `'c{plus}{plus}20'`, `'c{plus}{plus}23'`)

| `env.CxxModules()` / `--cxx-modules`
| Enable {cpp}20 modules for this env / all variants

| `env.HeaderUnit(path)`
| Register a header for BMI compilation (`'include/h.hpp'` or `'<span>'`)

| `env.Module(name, interface=…, implementation=…)`
| Compile/register a named module; objects link into a later `Build()` in the same env

| `env.ImportModules(dir)`
| Load `modules/module-map.json` + BMIs from a packaged library

| `env.CxxProfiles` / `CxxProfilesEnforce` / error-limit helpers
| Opt-in Profiles and per-TU diagnostic caps (see xref:cxx-profiles.adoc[{cpp} Profiles])
|===

Dialect and modules interact with toolchain defaults documented under
xref:toolchains.adoc#c-language-level[{cpp} language level] and the family pages.
A full modules walkthrough is in xref:cxx-modules.adoc[{cpp} Modules].

[source,python]
----
Import('env')

env.StdCpp('c++20')
env.CxxModules()
env.Module('math', interface='math.cppm', implementation=['math.cpp'])
env.Build('app', ['main.cpp'])
----
