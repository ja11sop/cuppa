= Method index
:description: Master index of Cuppa environment methods with descriptions and recommendations
:scons-man: https://scons.org/doc/production/HTML/scons-man.html

Grouped tables of methods you may call from a Cuppa `sconscript` after `Import('env')`.
Names this documentation covers link to the topic page that teaches them.
Others link to the unversioned https://scons.org/doc/production/HTML/scons-man.html[SCons man page]
(`#b-…` for builders, `#f-…` for functions).

Cuppa enhances SCons: write `Build()` and `Depends()` without a provenance prefix unless you are
contrasting a footgun. *Not recommended* marks vanilla SCons builders that skip Cuppa's variant /
`_build/` layout.

[cols="1,3"]
|===
| Column | Meaning

| Method
| Callable name as used in prose (`Name()`)

| Description
| What it does in a Cuppa project

| Notes
| Empty when the method is fine to call as documented.
*Not recommended* marks vanilla SCons builders that skip Cuppa's variant / `_build/` layout —
prefer the alternative named in the same cell.
Progress wrapping alone does *not* make a vanilla builder a substitute for `Build()` / `Compile()` /
`Build*Lib()` (see xref:methods.adoc#progress-tracking-and-variant-scoping[Progress tracking]).
|===

For tutorials and Related-method chains, start from the xref:methods.adoc[Methods] hub topic map.
