= `test_purge_dependencies` — purge trees and matching downloads
:description: Cuppa integration test documentation for test_purge_dependencies


== What is tested

With planted trees and archives under a private `--storage-root`:

* Combining any `--purge-*` flag with any `--remove-*` flag exits non-zero without deleting.
* Purging a GitLab package deletes the selected toolchain extract **and** its tarball, leaves
  another toolchain's extract and tarball, and reports download + `[E]` leaves plus leftover
  downloads. Verify hint is `--list-downloads`.
* SCons `-n` is a dry run: extract and archive stay on disk.
* Source `boost` with `storage_clean` deletes the download and selection-scoped products; the
  extract / headers stay.
* With `--develop`, the working copy is never deleted (a download for that name may still go).

== Generated files

Dummy project `sconstruct` declaring `boost_package` or `boost` / `widget`, plus planted folders
under `<storage>/dependencies/` and archives under `<storage>/downloads/` (including
`packages/<package>/<version>/`).

NOTE: These fixtures intentionally use the legacy ``dependencies`` /
``default_dependencies`` aliases so the suite still exercises them. Prefer
``import_dependencies`` / ``auto_enable_dependencies`` in new projects.

=== `sconstruct` (GitLab package — excerpt)

[source,python]
----
Boost = cuppa.package_dependency(
    'boost_package',
    package_manager='gitlab',
    registry='https://gitlab.example/api/v4/projects/1',
    package='boost',
    version='1.91',
)
cuppa.run(
    default_variants=['dbg'],
    dependencies=[Boost],
    default_dependencies=['boost_package'],
)
----

Source Boost purge uses ``default_dependencies=['boost']`` with ``--boost-home``.

== Commands

[source,sh]
----
cuppa -D --offline --purge-dependencies=boost_package --remove-dependencies=boost_package --storage-root=<storage>
cuppa -D --offline --dbg --purge-dependencies=boost_package --storage-root=<storage>
cuppa -D --offline --dbg -n --purge-dependencies=boost_package --storage-root=<storage>
cuppa -D --offline --dbg --boost-home=<extract> --purge-dependencies=boost --storage-root=<storage>
cuppa -D --offline --develop --purge-dependencies=widget --storage-root=<storage>
----

== Expected outcome

Successful purges print an announce line covering trees and downloads, a compact REMARK table with
download → `[E]` → source-asset / product nesting (partial marks when the extract stays), leftover
other-selection downloads/extracts, a freed-space summary that includes download bytes, and
`cuppa -Q -D --list-downloads`.
Dry-run uses “Would remove”. Combined purge+remove fails before any delete.
