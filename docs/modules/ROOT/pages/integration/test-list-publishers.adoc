= `test_list_publishers` — list and remove publisher trees
:description: Cuppa integration test documentation for test_list_publishers

== What is tested

With planted git-shaped trees under `<storage>/publishers/`, `--list-publishers`
prints a develop-shaped STATUS / SIZE / PUBLISHER / BRANCH / UPSTREAM / STATE /
PATH table, a severity summary, and the last-fetch note. `--list-format=json`
emits `publishers_root`, `tree_count`, and `entries` (including `status` /
`notes`). `--remove-publishers=NAME` with `-n` prints a list-shaped dry-run (REMARK
`would rm`) and leaves the tree; without `-n` REMARK is `removed` and the
named folder is deleted; a follow-up list shows the remaining tree.

== Generated files

A minimal `sconstruct` (`cuppa.run` with no package deps) plus two planted
publisher folders (`capy`, `corosio`) each with `.git/` and `sconstruct`.
