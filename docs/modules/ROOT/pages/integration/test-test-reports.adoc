= `test_test_reports` — HTML reports and collated index
:description: Cuppa integration test documentation for test_test_reports


== What is tested

1. *`GenerateHtmlTestReport`* — HTML + summary JSON from test report JSON after `--test`.
2. *`GenerateHtmlTestReport` with `--cov`* — ignores `coverage--*.json` beside `*.report.json` (no duplicate `coverage--*.html` targets).
3. *`CollateTestReportIndex`* — copies reports into `#_artifacts/test/` and writes `test-report-index.html` / `.json` at sconstruct end (including outside a VCS checkout).
4. *Shared-destination collate* — two sibling sconscripts collating into the same artifacts folder.
5. *`GenerateBittenReport`* — Bitten XML from the same test run.

== Generated files

=== Shared `sconstruct`

[source,python]
----
import cuppa

cuppa.run(default_variants=['dbg'])
----

=== HTML — `sconscript`

[source,python]
----
Import('env')
prog = env.BuildTest('hello_test', 'tests/hello_test.cpp')
env.GenerateHtmlTestReport(prog)
----

=== Collate index — `sconscript`

[source,python]
----
Import('env')
prog = env.BuildTest('hello_test', 'tests/hello_test.cpp')
reports = env.GenerateHtmlTestReport(prog)
env.CollateTestReportIndex(reports, destination='#_artifacts/test/')
----

=== Shared-destination collate

Root `sconscript` removed. Under `suite/`, `alpha_test.sconscript` / `beta_test.sconscript` each call `GenerateHtmlTestReport` then `CollateTestReportIndex(..., destination='#_artifacts/test/')`.

=== Bitten — `sconscript`

[source,python]
----
Import('env')
prog = env.BuildTest('hello_test', 'tests/hello_test.cpp')
env.GenerateBittenReport(prog)
----

== Command

[source,sh]
----
cuppa -D --offline --toolchains=gcc --dbg --test
# coverage JSON regression also uses:
cuppa -D --offline --toolchains=gcc --cov --test
----

== Expectations

* Exit 0; `*.report.html` and `*.report-summary.json` under `_build`.
* With `--cov`, HTML reports still build (no SCons duplicate-target failure on `coverage--*.html`).
* Collate scenarios: reports under `_artifacts/test/`, plus master `test-report-index.html` / `test-report-index.json`.
* Bitten: `*bitten*.xml` under `_build`.
