= Integration: {cpp} Profiles
:description: Opt-in --cxx-profiles / --cxx-profiles-enforce against a Profiles-capable Clang

Covered by `tests/integration/methods/test_cxx_profiles.py`.

Requires a Clang that accepts `-fprofiles` ({cpp} Alliance Profiles archives). When none
is on `PATH`, the smoke test **skips**. Set `CUPPA_TEST_PROFILES_TOOLCHAIN` to a
Profiles `clang{plus}{plus}` to force selection. The unsupported-toolchain case expects a
clear failure with a normal gcc/clang that lacks Profiles.

== Cases

[cols="3,4,3"]
|===
| Test | What it exercises | Notes

| `test_profiles_enforce_std_init_smoke`
| `--cxx-profiles --cxx-profiles-enforce=std::init` build
| Skips without Profiles Clang

| `test_profiles_enforce_composes_with_source_attribute`
| Source `[[profiles::enforce()]];` plus CLI `--cxx-profiles-enforce=std::init`
| Skips without Profiles Clang

| `test_profiles_report_emits_html_and_json`
| `--cxx-profiles-report` with enforce + error-limit disabled
| Writes `_artefacts/cxx-profiles/` HTML + JSON; skips without Profiles Clang

| `test_profiles_report_clean_removes_manifest_artefacts`
| Same report flags plus `--clean` on a second invocation
| Removes `.cuppa-reports` entries and listed HTML/JSON; skips without Profiles Clang

| `test_profiles_report_method_index_filters_undeclared_sconscript`
| Method-only index omits sibling sconscript scopes
| Two nested sconscripts; skips without Profiles Clang

| `test_profiles_report_cli_index_lists_all_sconscripts`
| `--cxx-profiles-report` bypasses the method-only filter
| Same fixture; skips without Profiles Clang

| `test_profiles_unsupported_toolchain_fails`
| `--cxx-profiles` on a non-Profiles toolchain
| Expects StopError / clear message
|===
