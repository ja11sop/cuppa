= `test_toolchains_matrix` — gcc / clang selection
:description: Cuppa integration test documentation for test_toolchains_matrix


== What is tested

`--toolchains=` selects the compiler family. The gcc case is skipped when gcc is not on PATH; clang is skipped (with a log) when clang is not installed.

Clang `--clang-stdlib=` dual coverage is **Linux-only**. When `CUPPA_TEST_ARGS`
already pins a stdlib for the current CI cell, only that variant runs. The gcc CI
job may have `clang{plus}{plus}` on PATH without `libc{plus}{plus}` packages — the
`libc{plus}{plus}` cell is then
omitted/skipped rather than failed. Windows / `CUPPA_TEST_TOOLCHAIN=vc` jobs skip
this test (LLVM clang on PATH is not a supported stdlib matrix there).
