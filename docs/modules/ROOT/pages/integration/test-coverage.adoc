= `test_coverage` — `Coverage` and `CollateCoverageIndex`
:description: Cuppa integration test documentation for test_coverage


== What is tested

With `--cov --test`:

* `Coverage` runs gcov-based coverage for a `BuildTest` binary.
* `CollateCoverageFiles` / `CollateCoverageIndex` collate per-test coverage into a shared `#_artefacts/coverage/` tree from two sibling sconscripts (regression for mid-action `Install` clashes on `by-source` pages).
* Two independent `BuildTest` binaries under `--cov --test --parallel` succeed and do not print the old parallel-collection warning. `--cov --parallel` without `--test` builds the instrumented tree and does not collect.

Skipped (with log) if `gcov` / `gcovr` are not on PATH, or when `CUPPA_TEST_TOOLCHAIN` is MSVC (`vc` / `cl` / `msvc`).

== Generated files

=== Shared `sconstruct`

[source,python]
----
import cuppa

cuppa.run(default_variants=['dbg'])
----

=== `Coverage` scenario — `sconscript`

[source,python]
----
Import('env')
prog = env.BuildTest('hello_test', 'tests/hello_test.cpp')
env.Coverage(prog, 'tests/hello_test.cpp')
----

=== Shared-destination collate scenario

Root `sconscript` is removed. Under `suite/`:

`suite/alpha_test.sconscript` and `suite/beta_test.sconscript` (same pattern):

[source,python]
----
Import('env')
prog = env.BuildTest('alpha_test', 'alpha_test.cpp')
cov = env.CollateCoverageFiles(prog, destination='#_artefacts/coverage/')
env.CollateCoverageIndex(cov, destination='#_artefacts/coverage/')
----

== Command

[source,sh]
----
cuppa -D --offline --toolchains=gcc --cov --test
----

Parallel collection (two independent single-file tests, no shared library):

[source,sh]
----
cuppa -D --offline --toolchains=gcc --cov --test --parallel
----

Instrumented compile only (no tests, no collection):

[source,sh]
----
cuppa -D --offline --toolchains=gcc --cov --parallel
----

== Expectations

* Exit 0; coverage artifacts under `_build` and/or `COVERAGE` in stdout for the `Coverage` scenario.
* For the collate scenario: `coverage-index--*.html` under `_artefacts/coverage/`, with by-source pages namespaced as `by-source/<index-stem>/...html` so sibling sconscripts can share the destination safely.
* Two independent tests under `--cov --test --parallel` exit 0 and do not print `Collecting coverage with SCons -j is not reliable`.
* The shared-library fixture (serial and parallel) checks that each test has its own `shared.gcda` under `gcov-data/{program}`.
* `--cov --parallel` without `--test` exits 0 and does not print that sentence either.
