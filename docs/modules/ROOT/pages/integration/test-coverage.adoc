= `test_coverage` — `Coverage`
:description: Cuppa integration test documentation for test_coverage


== What is tested

With `--cov --test`, `Coverage` runs gcov-based coverage for a `BuildTest` binary. Skipped (with log) if `gcov` is not on PATH.

== Generated files

=== `sconstruct`

[source,python]
----
import cuppa

cuppa.run(default_variants=['dbg'])
----

=== `sconscript`

[source,python]
----
Import('env')
prog = env.BuildTest('hello_test', 'tests/hello_test.cpp')
env.Coverage(prog, 'tests/hello_test.cpp')
----

== Command

[source,sh]
----
cuppa -D --offline --toolchains=gcc --cov --test
----

== Expectations

Exit 0; coverage artifacts under `_build` and/or `COVERAGE` in stdout.

Note: `CollateCoverageFiles` / `CollateCoverageIndex` are not exercised here (see methods README deferred list).
