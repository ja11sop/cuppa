== CI notes

* Linux CI: full suite × `gcc`, `clang`+libstdc++, `clang`+libc++
* Windows CI: full integration with `vc` (header units, `import std` when `std.ixx` present, shared libs with DLL exports)
* macOS CI: Homebrew LLVM slice (named / header / sugar)
* `import std` on Clang may select a versioned toolchain that ships `std.cppm`
* Too-old GCC/Clang on Linux **fail** rather than skip
