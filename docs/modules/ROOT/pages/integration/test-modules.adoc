== Toolchain selection

* Linux CI: `gcc`, `clang`+libstdc++, `clang`+libc++
* macOS CI: modules slice installs **Homebrew LLVM** Clang + libc++ (not Xcode Apple Clang),
  and passes `--propagate-path` so SCons does not fall back to `/usr/bin/clang++`.
  Apple Clang is rejected: it reports high majors but does not ship `clang-scan-deps` / a modules-capable toolchain.
  See xref:cxx-modules.adoc#macos-apple-clang[macOS: Apple Clang vs LLVM Clang].
* Windows CI: full integration with `vc` (named modules; header/`import std` skipped)
* **Fail** (do not skip) if no Linux GCC 14+ / Clang 16+ driver is on PATH when those families are selected
* `import std` on Clang may select a versioned toolchain that ships `std.cppm`
