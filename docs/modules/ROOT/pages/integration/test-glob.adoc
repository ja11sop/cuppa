= `test_glob` — `StaticGlob`, SCons `Glob`, and `Filter`
:description: Cuppa integration test documentation for test_glob


== What is tested

- `StaticGlob(..., recursive=False)` lists `*_test.cpp` under `tests/` (at least two files).
- `StaticGlob` finds nested `src/nested/deep.cpp`, including with `start='#/src'`.
- Deprecated `GlobFiles` / `RecursiveGlob` aliases still work and emit one warning each.
- `Filter` works on `StaticGlob` nodes with project-relative patterns and `*/detail/*` excludes.
- SCons `Glob('#/src/**/*.cpp')` is **not** a full tree walk (one path segment only); `StaticGlob` covers the tree.
- Flat-dir recipe: `Glob('#/tests/*.cpp')` then `Filter` (including building from a filtered node).
- Discovered sources can be built (`BuildTest`, `Compile`).

== Generated files

=== `sconscript` (representative)

[source,python]
----
Import('env')
env.AppendUnique(CPPPATH=['#/include'])
tests = env.StaticGlob('*_test.cpp', start='tests', recursive=False)
assert len(tests) >= 2
deep = env.StaticGlob('*.cpp', start='src')
assert any('deep.cpp' in str(n).replace('\\','/') for n in deep)
anchored = env.StaticGlob('*.cpp', start='#/src')
assert any('deep.cpp' in str(n).replace('\\','/') for n in anchored)
env.BuildTest('hello_test', 'tests/hello_test.cpp')
env.Compile('src/nested/deep.cpp')
----

== Command

[source,sh]
----
cuppa -D --offline --toolchains=gcc --dbg --test
----

== Expectations

Exit 0; `hello_test` under `final/`; `deep.*` object under `_build` where compiled.
