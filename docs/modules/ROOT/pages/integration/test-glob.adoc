= `test_glob` — RecursiveGlob, GlobFiles, SCons Glob, and Filter
:description: Cuppa integration test documentation for test_glob


== What is tested

- `RecursiveGlob` walks nested trees (including `start='#/src'`).
- `GlobFiles` lists only one directory (no nested `deep.cpp`).
- SCons `Glob('#/src/**/*.cpp')` is one path segment only; `RecursiveGlob` covers the tree.
- `Filter` works on RecursiveGlob and Glob nodes (relative patterns, `*/detail/*` excludes, build from filtered node).
- Snapshot vs directory Glob: both see a new top-level file on the next Cuppa invocation.
- Deprecated `StaticGlob` umbrella warns toward RecursiveGlob / GlobFiles; those two do not warn.
- Discovered sources can be built (`BuildTest`, `Compile`).

== Command

[source,sh]
----
cuppa -D --offline --toolchains=gcc --dbg --test
----
