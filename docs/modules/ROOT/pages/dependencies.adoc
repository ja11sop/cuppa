= Dependencies
:description: What a dependency is, how to declare one, and which page to read next

Dependencies encapsulate include paths, defines, library linkage, and optional download/build
steps. Trees live under `--dependencies-root` (and archives under `--downloads-root`) — see
xref:build-layout.adoc[Build layout].

Start with xref:dependencies/overview.adoc[Dependencies overview] for the shared declaration
model, then choose the detailed page for the dependency kind or workflow you need.
