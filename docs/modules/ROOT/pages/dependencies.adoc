= Dependencies
:description: Using, Managing, Publishing, and Authoring — which hub to open next

Dependencies encapsulate include paths, defines, library linkage, and optional download/build
steps. Trees live under `--dependencies-root` (and archives under `--downloads-root`) — see
xref:build-layout.adoc[Build layout].

Cuppa's dependency docs are organised by **job**. Start with **Using** unless you already
know you need storage reclaim, publishing, or a custom factory.

== Hubs

[cols="1,2"]
|===
| Hub | When to open it

| xref:dependencies/using.adoc[Using dependencies]
| Declare and consume location, package, Conan, and built-in dependencies.
  Includes
  xref:dependencies/using/building-with-packages.adoc[building a tip against nested packages]
  without learning how to publish that nest.

| xref:dependencies/managing.adoc[Managing dependencies]
| List, remove, purge, wipe, and check develop copies under storage.
  Option A `--list-scope` and requires-forest samples live under
  xref:dependencies/managing/list-dependencies.adoc[Listing dependency trees].

| xref:dependencies/publishing.adoc[Publishing dependencies]
| Ship Cuppa-built packages, cascade nest publishes, amend/external builds, and
  publisher trees.

| xref:dependencies/authoring.adoc[Authoring dependencies]
| Write custom dependency factories, storage hooks, and plugins.
|===
