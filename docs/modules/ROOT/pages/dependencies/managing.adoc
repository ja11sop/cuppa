= Managing dependencies
:description: List, remove, purge, inventory, and develop working copies

Cuppa stores retrieved dependency trees under `--dependencies-root` and archives under
`--downloads-root`. This section is about **inspecting and reclaiming** that storage, and about
checking **develop** working copies — not about declaring dependencies (see
xref:dependencies/using.adoc[Using dependencies]).

[#which-listing]
== Which listing for which question

Cuppa has several read-only reports that answer different questions. `--develop` is a *build*
switch; `--list-develop` is a *report* about working copies. They are easy to mix up.

[cols="3,3,4"]
|===
| You want to know…
| Use
| Looks at

| What is under the shared dependencies root, and which trees this project would use
| `--list-dependencies` (optional `--list-scope`)
| `--dependencies-root` (for example `~/.cuppa/dependencies` or a legacy `~/_cuppa/_download`)

| What archives sit under the downloads root, and which trees they feed
| `--list-downloads` (optional `--list-scope`)
| `--downloads-root` (for example `~/.cuppa/downloads` or a legacy `~/_cuppa/_cache`)

| What publisher working copies sit under the cascade forest (git health + size)
| `--list-publishers` (see xref:dependencies/publishing/list-publishers.adoc[Listing publisher trees])
| In-force publisher root (`--publisher-root`, else `~/.cuppa/publishers`); develop-shaped STATUS report

| Branch, cleanliness, and ahead/behind of configured develop working copies
| `--list-develop`
| Develop paths from the sconstruct

| What is under ``_build``
| `--list-builds`
| `--build-root`
|===

**Inspecting dependency storage** — omit `--develop`:

[source,shell]
----
cuppa -Q -D --list-dependencies
----

Resolve marks the tree this project would use (without develop) with leaf state
`referenced`, and sibling branches or other leftovers as `unreferenced`. The default listing
groups those as **used** then **unused**; pass ``--list-scope=resolve`` for the Pass A
referenced / unreferenced identity view. That is the listing to use before reclaiming disk.

**Inspecting develop checkouts** — also omit `--develop` unless you want the banner to say it is
active; the table is the same either way:

[source,shell]
----
cuppa -Q -D --list-develop
----

**`--list-dependencies --develop` is uncommon.** Passing `--develop` makes resolve point at
working copies, so cache trees for those identities are no longer `in use`; the dependency name
row shows `develop` instead (the branches themselves stay unmarked). Use that only when you care
how the storage table would look under a develop resolve — not as the default storage listing,
and not instead of `--list-develop`.

[source,shell]
----
# Storage under a develop resolve (optional)
cuppa -Q -D --list-dependencies --develop
----
