= Built-in dependencies
:description: Registered built-in dependency names and when to use them

Cuppa registers some dependencies by module scan. Use a built-in when you want that
integration; use a xref:dependencies/using/location.adoc[location],
xref:dependencies/using/packages.adoc[package], or xref:dependencies/using/conan.adoc[Conan] dependency
when you are wiring an external tree yourself.

[cols="3,5,2"]
|===
| Name | Purpose | Page

| `boost`
| Source Boost via Boost.Build (`b2`)
| xref:dependencies/using/builtins/boost.adoc[Boost]

| `qt4` / `qt5`
| SCons Qt MOC/UIC/RCC tools
| xref:dependencies/using/builtins/qt.adoc[Qt4 and Qt5]

| `quince` (+ backends)
| Quince ORM as location wiring
| xref:dependencies/using/builtins/quince.adoc[Quince]
|===

`boost_package` is **not** a built-in. It is a GitLab `package_dependency` helper — see
xref:dependencies/using/gitlab.adoc#boost-package[Boost from the registry].
