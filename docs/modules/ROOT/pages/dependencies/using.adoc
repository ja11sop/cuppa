= Using dependencies
:description: Declare and consume location, package, Conan, and built-in dependencies

Use this hub when you want a green build that **consumes** dependencies — including an
application that pulls nested registry packages — without learning how to publish that
stack.

Cuppa supports more than one package supply chain. **GitLab generic packages** and
**Conan** are both first-class consume paths; pick the one that matches how your
artefacts are published. Location dependencies remain the path for VCS and archive trees
you manage yourself.

When you need to inspect or reclaim storage, go to
xref:dependencies/managing.adoc[Managing dependencies].
When you maintain or ship package artefacts, go to
xref:dependencies/publishing.adoc[Publishing dependencies].
