= Publishing dependencies
:description: Ship Cuppa-built packages, cascade nest publishes, and manage publisher trees

Use this hub when you **maintain or ship** package artefacts — GitLab registry uploads,
cascading nest publishes, amend/external builds, Conan publish, and publisher working copies.

If you only need a tip application to **build against** nested packages already in the
registry (or under `--develop`), start with
xref:dependencies/using/building-with-packages.adoc[Building with package dependencies]
instead.
