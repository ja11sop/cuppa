To reclaim storage from an in use dependency use one of:
│
├── cuppa -Q -D -n --remove-dependencies=<name>
│   └── to remove the active-context extract or products (downloads stay)

│   └── to also remove matching downloads for the same active context

│
├── cuppa -Q -D -n --force-wipe-dependencies=<token>
│   └── to wipe named list-tree leaves (including unused siblings under a used identity); <token> may use [selector]name/qualifier
└── cuppa -Q -D -n --force-wipe-unreferenced-dependencies
    └── orphan sweep for every unreferenced leaf this resolve sees (prefer named tokens above)
