Cuppa
=====

**Note:** The PyPI long description is maintained in ``README.pypi.md``.
This file is kept for compatibility with older packaging checkouts.

Cuppa is an extensible C++ build system on top of
`SCons <https://www.scons.org/>`__.

::

    pip install cuppa

Documentation: https://ja11sop.github.io/cuppa/
