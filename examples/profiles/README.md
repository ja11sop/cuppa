# Profiles examples

Deliberate C++ Profiles violations for documentation, classifier fixtures, and manual
Clang capture. Each profile has its own subdirectory:

| Directory | Profile | Purpose |
|-----------|---------|---------|
| `std-init-violations/` | `std::init` | All twelve documented initialization rules (P4222) |

Future profiles (for example `std::type`) will follow the same layout under this tree.
